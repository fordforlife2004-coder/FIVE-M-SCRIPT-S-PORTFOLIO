# Security Policy

## Supported versions

| Script | Supported |
| --- | --- |
| Admin Menu, ELS, Vehicle Spawn, Vehicle Skins and Iowa Police 2.1.x | Yes |
| Prest_Sector Cuffs and Prest_Sector CAD 1.1.x | Yes |
| Older 2.0 and 1.0 versions | Please update first: the server console tells you when there's a newer version |
| The v1 originals in [legacy-v1](legacy-v1/) | No, they're kept for comparison only |

## Reporting a vulnerability

To report a vulnerability, please email fordforlife2004@gmail.com. Please don't open a public issue
for it, so it isn't used against servers before there's a fix.

Vulnerabilities that are reported will be fixed right away! When reporting, please explain:
- which script and version it's in,
- what kind of vulnerability it is and how someone could use it (steps to reproduce help a lot),
- how dangerous it is: what it could let a player or cheat do on a server.

Reports without these details may not be looked at.

## Reporting a bug

When reporting a bug, please explain what happened, what you expected to happen instead, and how to
make it happen again. Send it to the same email as vulnerabilities.

Thank you, PrestSectz.
